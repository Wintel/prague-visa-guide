# Prague Visa Guide

An anonymous, static guide to the Czech short-stay Schengen visa process for two traveller roles:

- conference attendee (`MICE`)
- accompanying tourist (`Tourism`)

## Pages

- `index.html` — detailed Chinese step-by-step guide
- `simulation.html` — original low-poly, isometric visa-process simulation

The site has no analytics, advertising, cookies, or personal-information forms. Simulation progress is stored only in the visitor's browser using `localStorage` and can be cleared from the page.

Visa information was checked on 2026-08-10. Applicants should verify all requirements against the official links included on the site before applying.
